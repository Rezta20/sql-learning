# 怎麼用（給 Sasha 自己看的說明書）

> App 裡也有這一頁：頂端分頁「說明」（`/guide`）。忘了就回來看。
> 每天只要記住一件事：打開 App，按畫面上唯一那顆大按鈕。

## 1. 每天的 45 分鐘（平日 14:00）

1. **打開 OrbStack** — 開著就好，資料庫才會活著。
2. **筆記本、筆** — 卡片區（可撕小卡）＋錯誤日誌區。
3. **按「開始 45 分鐘」** — 頁首計時器，會照「暖身 → 概念 → 抄卡 → 動手 → Boss → 結算」提醒。
4. **複習到期的卡** — 今天頁有藍色那行「今天有 N 張卡要複習」才需要；沒有就跳過。
5. **按「開始」貼給老師** — 今天頁的大橘鈕，會複製一句話 → Cursor 聊天框 Cmd+V、Enter。
6. **照畫面一步一步做** — 關卡頁一次只給一步：概念 → 手寫卡 → 3 題 → 專案題 → 講出來 →（最後一課）Boss。
7. **最後按「結算」貼給老師** — 關卡頁最後一步的紫色鈕，老師會寫日誌、更新進度。

週末不上新課，只複習到期的卡。

## 2. 只在三個時刻找老師

- **開始**：今天頁大橘鈕。老師抽問 1 張到期卡、講一個概念、給今天的手寫卡。
- **卡住，而且字典查不到**：右下角「卡住」→ 貼錯誤那一行 → 沒命中才按「問老師」。
- **結算**：關卡頁最後一步的紫色鈕。老師存日誌、更新 `study/progress.md`、給今天的手寫卡總表。

這三顆按鈕都只是「複製一句話」。按完到 Cursor 聊天框 Cmd+V、Enter，老師就知道該做什麼。其他時間都在 App 裡自己做。

## 3. 每一題都自己對答案

1. 先自己寫、在 psql 跑。
2. 卡了 → 點「提示」。
3. 跑出來了 → 點「預期結果」，跟螢幕一樣就按「結果跟預期一樣 ✓」。
4. 還是不一樣 → 點「看答案」，找出哪個字打錯。

「講出來」要自己勾滿 3 個關鍵字才能過；Boss 題自己判定過不過。真的不懂再用小字「問老師」。

## 4. 對老師只需要這幾句

| 句子 | 從哪裡按 | 老師會做什麼 |
| --- | --- | --- |
| 開始今天的課 | 今天頁大橘鈕 | 暖身抽卡 → 一個概念 → 手寫卡 |
| 太多了 | 右下角紅鈕 | 濃縮成 3 行、只給一件事 |
| 卡住了 | 卡住頁「問老師」（再補截圖） | 只說哪個字錯、怎麼改 |
| 結算 | 關卡頁最後一步 | 存日誌、更新進度、卡片總表 |

貼截圖或結果時，老師只回「對／錯 + 一句原因」。

## 5. 進度不會弄丟

- 打勾、XP 存在這台電腦的瀏覽器裡，關機重開不會消失。
- 換電腦或怕清掉：頁首雲朵 → `/sync`，貼一次 GitHub token（只要 `gist` 權限）就會自動備份。
- 老師的紀錄（`study/progress.md`、`study/journal/`）在 repo 裡，開新對話老師會自己讀。
